# Generated outputs

The committed outputs contain the rule-based baseline and basic dataset summaries only. BERT prediction, training, XAI, and sentiment files are generated by the scripts after installing `requirements-bert.txt` / `requirements-sentiment.txt` and running the documented workflow.

The rule outputs were regenerated with the current sentence-window rules (`window_size=2`) on the frozen review-level split (`data/processed/review_splits.csv`, seed 42): 1,233 clauses across 130 reviews, with 207 clauses in the held-out test partition. Earlier committed rule outputs came from an older version of the rules and should not be cited. The test partition contains only six `Multiple Destinations` examples (flagged in `low_support_classes`), so estimates for that class are especially uncertain. These results are preliminary and should not be presented as final until the supplied annotations have been checked.

Files here include raw and row-normalized rule confusion matrices (`figures/rule_confusion_matrix*.png`) and low-support flags in `rule_metrics.json`, `rule_metrics_per_class.csv`, and `tables/data_quality_summary.json`.
